## Resumo

O presente relatório de PAP descreve o desenvolvimento do TeamCore, uma aplicação de gestão de RH concebida para simplificar os processos desse setor. O projeto foi motivado pela necessidade de uma ferramenta de RH que fosse simples e fluida de usar, contrastando com a complexidade de muitos sistemas existentes.

O TeamCore foi desenvolvido com o objetivo de alcançar uma gestão abrangente de dados de funcionários, cargos e contratos, promover a automação de processos para minimizar a margem de erro, e fornecer suporte à decisão através de relatórios e gráficos estratégicos. A qualidade técnica, focada na usabilidade, segurança e performance robusta, foi um pilar central do desenvolvimento.

A metodologia de trabalho incluiu o levantamento detalhado de requisitos, a modelação da base de dados relacional, e o desenvolvimento técnico utilizando a framework Laravel com a extensão Filament para o backend e frontend. O processo foi complementado por entrevistas com profissionais da área para validação das funcionalidades essenciais (MVP) e testes rigorosos de funcionalidade.

**Nota sobre o Estado do Projeto:** No momento da redação deste relatório (30 de Janeiro de 2026), o projeto TeamCore encontra-se completamente concluído e funcional, com todas as funcionalidades principais implementadas, validadas e refinadas. A aplicação encontra-se estável, com sistema de autorização robusto, múltiplos painéis especializados, widgets dinâmicos baseados em roles, e está pronta para implementação imediata em ambiente produtivo.

## Introdução

### Motivação e Contexto

O TeamCore nasce da necessidade de uma ferramenta de Gestão de Recursos Humanos intuitiva e eficiente, capaz de apoiar tanto equipas de gestão como colaboradores nas operações diárias. A solução foi concebida para centralizar a gestão de funcionários, cargos e contratos, automatizar tarefas de registo de tempo e horas extras, e fornecer suporte à decisão através de relatórios e visualizações estruturadas.

### Objetivos Principais

Este projeto PAP visa desenvolver um sistema de gestão que:

- **Centraliza dados de RH:** Consolidar informação de funcionários, departamentos, designações, contratos e períodos de férias numa base de dados estruturada e facilmente consultável.
- **Automatiza registos de trabalho:** Permitir o registo eficiente de horas trabalhadas, com suporte a pausas/almoços, cálculo automático de horas extras e manutenção atualizada do banco de horas individual.
- **Implementa controlo de acesso granular:** Segregar permissões por função de utilizador (ROOT, ADMIN, HR, EMPLOYEE), garantindo que cada utilizador acede apenas aos dados e funcionalidades apropriados.
- **Oferece experiência de utilizador optimizada:** Proporcionar uma interface intuitiva, traduzida para Português (pt-Pt), com notificações contextuais e confirmações para prevenir ações não intencionais.
- **Garante qualidade técnica:** Assegurar a aplicação através de testes automatizados, validação de regras de autorização e boas práticas de segurança.

### Abordagem e Metodologia

O desenvolvimento foi realizado em ciclos iterativos, adotando:

- **Tecnologias modernas:** Laravel 12 com Filament 3 como framework de desenvolvimento, PHP 8.1+ e MySQL para persistência de dados.
- **Validação com especialistas na área:** Entrevistas e testes manuais contínuos com utilizadores e profissionais da área.
- **Testes automatizados:** Suite de testes Pest para validar funcionalidades críticas e regressões.
- **Boas práticas de engenharia:** Isolamento de dados ao nível do modelo, políticas de autorização bem definidas, e padrões de código consistentes.

O processo incluiu registo detalhado de alterações e validações manuais após cada implementação significativa.

## Desenvolvimento do projeto

### Metodologia e ferramentas

O projeto foi desenvolvido em ciclos iterativos utilizando a framework **Laravel 12** com **Filament 3** como painel administrativo, **PHP 8.1+** e **MySQL 8.0+** para persistência de dados. A base de dados foi modelada para suportar entidades como Funcionários, Contratos, Departamentos, Banco de Horas, Registos de Trabalho, Férias e Licenças. O desenvolvimento adotou práticas de testes automatizados com **Pest**, validação contínua com especialistas da área, documentação detalhada e registo sistemático de alterações.

### Stack Tecnológico

| Componente | Versão | Propósito |
|-----------|--------|----------|
| Laravel | 12 | Framework backend |
| Filament | 3.x | Panel administrativo e UI |
| PHP | 8.1+ | Linguagem de programação |
| MySQL | 8.0+ | Base de dados relacional |
| Livewire | 3.x | Componentes reativos |
| Tailwind CSS | 3.x | Framework CSS |

### Arquitetura de Autorização

Implementou-se um sistema hierárquico de funções (roles) com controlo granular de acesso:

**ROOT (Superadministrador)**
- Acesso total a todos os recursos
- CRUD completo em qualquer item
- Acesso a painéis: /admin, /app, /hr, /employee
- Controlo total do sistema

**ADMIN (Administrador)**
- Acesso quase total sem permissão de gestão de utilizadores
- Pode CRUD funcionários, contratos, departamentos, designações
- Acesso a painéis: /admin, /app
- Gestão de registos de trabalho e férias

**HR (Recursos Humanos)**
- Acesso limitado à gestão de RH
- Permissões READ/CREATE/UPDATE (sem DELETE) em dados de RH
- Acesso a painéis: /app, /hr
- Não pode eliminar nenhum item
- Visualiza métricas e relatórios

**EMPLOYEE (Funcionário)**
- Acesso muito limitado a dados pessoais
- Pode visualizar apenas seus registos de trabalho, férias e banco de horas
- Pode criar solicitações de férias, justificativas e licenças
- Acesso apenas ao painel: /employee
- Isolamento completo de dados de terceiros

### Sistema de Painéis e Interfaces

Implementaram-se quatro painéis especializados com middleware dedicado:

**Painel /app (Dashboard Padrão)**
- Acesso: Todos os utilizadores
- Widgets: Estatísticas globais, gráficos de contratos e férias
- Navegação: Recursos conforme role
- Dark Mode: Totalmente suportado

**Painel /admin (Dashboard Admin)**
- Acesso: ROOT, ADMIN
- Widgets: Visão completa do sistema (10 widgets dinâmicos)
- Menu: Gestão de utilizadores, funcionários, contratos, departamentos
- Funcionalidade: CRUD completo com auditoria

**Painel /hr (Dashboard RH)**
- Acesso: ROOT, ADMIN, HR
- Widgets: Métricas de RH, distribuição departamental, gráficos de férias
- Menu: Gestão de funcionários, contratos, solicitações, designações
- Funcionalidade: Gestão de dados de RH sem capacidade de eliminação

**Painel /employee (Dashboard Empregado)**
- Acesso: EMPLOYEE
- Widgets: Informações pessoais, resumo de horas, histórico de banco de horas
- Formulários: Solicitação de férias, licenças e justificativas
- Dados: Isolamento completo - apenas informação pessoal

### Sistema de Widgets com Visibilidade Dinâmica

Implementou-se trait **WidgetVisibility** para controlo centralizado de visibilidade de widgets baseado em roles. O sistema renderiza dinamicamente 12 widgets, com filtragem em tempo de renderização (render time) evitando problemas com contexto de autenticação.

**Widgets Globais (10) - Visibilidade por Role:**
- **StatsOverview**: 4 cards (Utilizadores, Funcionários, Contratos, Férias)
- **ContractsChart**: Gráfico de barras por tipo de contrato
- **DepartmentDistributionChart**: Gráfico de rosca por departamento
- **TimeoffsChart**: Gráfico de rosca por status de férias
- **WeeklyWorklogChart**: Gráfico de linhas - horas semanais
- **AverageHoursWidget**: 3 cards (Média mês, 30 dias, extras)
- **HoursbankHistoryWidget**: Gráfico histórico 30 dias
- **DashboardOverviewWidget**: Visão geral do sistema
- **RecentAuditLogsWidget**: Registos recentes de auditoria
- **LicenseInformationWidget**: 3 cards (Total, Pendentes, Aprovadas)

**Widgets Exclusivos de Employee (2):**
- **EmployeeInfoWidget**: Informações pessoais + estatísticas
- **WorklogSummaryWidget**: Resumo mensal + últimos 10 registos

### Funcionalidades Principais Implementadas

**1. Gestão de Funcionários**
- CRUD com isolamento automático para employees
- Criação automática de Hoursbank ao criar funcionário
- Campos: Nome, Email, Data de Admissão, Departamento, Cargo, Status
- Notificações de criação e atualização

**2. Rastreamento de Horas com Precisão**
- Registo de entrada/saída com suporte a pausas
- Cálculo automático: Horas Trabalhadas = (Fim - Início - Pausa) / 60
- Horas Extras = max(0, Horas Trabalhadas - 8)
- Validações: Pausa ≤ 2 horas, dentro do horário de trabalho
- Arredondamento automático para números inteiros
- Isolamento completo para employees

**3. Banco de Horas**
- Atualização automática ao registar horas extras
- Visualização em widgets com histórico de 30 dias
- Rastreamento de saldo acumulado
- Acessível a HR/Admin para gestão, a Employee para visualização

**4. Solicitações de Férias e Licenças**
- Tipos: Férias (vacation), Justificativa (justification), Licença (license)
- Status: Pendente, Aprovada, Recusada
- Fluxo: Employee submete → HR aprova/rejeita → Notificação
- Campos: Data início/fim, motivo, status com badges coloridas
- Isolamento: Employee vê apenas suas solicitações

**5. Sistema de Notificações Personalizado**
- Trait NotifiesCreatedItems: Notifica ao criar itens
- Trait NotifiesUpdatedItems: Notifica ao editar itens
- Trait ConfirmsCancelAction: Confirmação antes de cancelar edições
- Persistência: Histórico em notification_logs
- UI: Bell icon com contador e dropdown de histórico

**6. Localização Completa (i18n)**
- Interface traduzida para Português (pt-PT)
- Todas as labels, campos, validações e mensagens
- Suporte a Dark Mode integrado
- Datas e tempos formatados conforme locale

**7. Segurança e Auditoria**
- Senha padrão: passexemplo123 (hasheada)
- Flag must_change_password ativada para novos utilizadores
- Policies de autorização em todas as operações
- Gates reforçados com verificação de UserRole
- Isolamento de dados ao nível do modelo
- Middleware dedicado para proteção de rotas

**8. Melhorias UX**
- Confirmação de cancelamento ao editar
- Badges de função na tabela de utilizadores
- Ações condicionais visíveis apenas para roles autorizados
- Tooltips explicativos
- Validações em tempo real
- Responsividade completa (mobile, tablet, desktop)

**9. API RESTful Documentada**
- 18+ endpoints com suporte a CRUD completo
- OpenAPI 3.0 specification integrada
- Swagger UI interativa em /swagger-ui.html
- Suporte a paginação, filtros, busca
- Error handling estruturado
- Versionamento (/api/v1)

**10. Sistema de Auditoria Avançado**
- Filament UI para visualização de logs
- Export para CSV
- Dashboard widget com alterações recentes
- Limpeza automática de logs antigos (90+ dias)
- Delta display visual das mudanças
- Rastreamento completo: quem, o quê, quando

**11. Sistema de Jornada Flexível**
- Tipos: Fixa (8h), Flexível (6.5-9.5h), 4x3 (4 dias/3 folga)
- Controlo granular de horas por dia
- Integração com registos de trabalho

**12. Avaliação de Desempenho**
- Rating scale: 1 a 5 estrelas
- Períodos: Semestral, Anual, Experiência
- Rastreamento de metas e recomendações

**13. Gestão de Benefícios**
- Catálogo organizacional
- Tipos: Mensal, Anual, Único
- Atribuição a funcionários com rastreamento
