Resumo

O presente relatório de PAP descreve o desenvolvimento do TeamCore, uma aplicação de gestão de Recursos Humanos concebida para simplificar os processos administrativos e operacionais desse setor. O projeto foi motivado pela necessidade de uma ferramenta intuitiva e eficiente, capaz de centralizar a gestão de funcionários, departamentos, designações, contratos e períodos de férias.

O TeamCore foi desenvolvido com os seguintes objetivos: (1) Centralizar dados de RH numa base de dados estruturada e facilmente consultável; (2) Automatizar registos de trabalho com cálculo automático de horas extras e manutenção do banco de horas; (3) Implementar controlo de acesso granular segregando permissões por função de utilizador (ADMIN, HR, EMPLOYEE); (4) Oferecer uma experiência de utilizador otimizada com interface intuitiva traduzida para Português (pt-PT) e notificações contextuais; (5) Garantir qualidade técnica através de testes automatizados e boas práticas de segurança.

A metodologia de trabalho incluiu o levantamento detalhado de requisitos, a modelação da base de dados relacional, e o desenvolvimento técnico utilizando a framework Laravel 12 com a extensão Filament 3 para o backend e frontend. O processo envolveu múltiplos ciclos iterativos, validação contínua com especialistas através de testes manuais, suite de testes automatizados com Pest/PHPUnit, e implementação de boas práticas de engenharia de software.

O projeto TeamCore encontra-se em fase avançada de desenvolvimento, com funcionalidades essenciais implementadas e testes de validação em curso. A aplicação demonstra potencial significativo para aumentar a eficiência operacional, automatizar processos repetitivos, minimizar erros administrativos e fornecer suporte à decisão através de dados consolidados.





Introdução

Motivação e Contexto

O TeamCore nasce da necessidade de uma ferramenta de Gestão de Recursos Humanos intuitiva, eficiente e centralizada. A solução foi concebida para apoiar tanto equipas de gestão quanto colaboradores nas operações diárias, consolidando a gestão de funcionários, departamentos, designações, contratos, registos de tempo, banco de horas e períodos de férias numa plataforma única.
 
Objetivos Principais

Este projeto PAP visa desenvolver um sistema de gestão que:

1. **Centraliza dados de RH:** Consolidar informação de funcionários, departamentos, designações, contratos, períodos de férias e benefícios numa base de dados relacional estruturada e facilmente consultável.

2. **Automatiza registos de trabalho:** Permitir o registo eficiente de horas trabalhadas com suporte a pausas/almoços, cálculo automático de horas extras, validação de períodos de trabalho e manutenção atualizada do banco de horas individual de cada funcionário.

3. **Implementa controlo de acesso granular:** Segregar permissões por função de utilizador (ADMIN, HR, EMPLOYEE), garantindo que cada utilizador acede apenas aos dados e funcionalidades apropriados através de políticas de autorização bem definidas.

4. **Oferece experiência de utilizador otimizada:** Proporcionar uma interface intuitiva completamente traduzida para Português (pt-PT), com notificações contextuais, confirmações para prevenir ações não intencionais, e dashboards personalizados com métricas-chave.

5. **Implementa políticas de segurança robustas:** Padronizar senhas iniciais para novos utilizadores com obrigatoriedade de mudança no primeiro acesso, validar acesso por painel de acordo com a função do utilizador, e garantir isolamento de dados ao nível do funcionário.

6. **Garante qualidade técnica:** Assegurar a aplicação através de testes automatizados (Pest/PHPUnit), validação rigorosa de regras de autorização, boas práticas de segurança e padrões de código consistentes.

Abordagem e Metodologia

O desenvolvimento foi realizado em ciclos iterativos, adotando:

- **Tecnologias modernas:** Laravel 12 com Filament 3 como framework de desenvolvimento integrado, PHP 8.2+ e MySQL para persistência de dados relacional.
- **Arquitetura modular:** Organização em painéis separados (Admin, HR, Funcionário) com middleware e políticas específicas para isolar responsabilidades e dados.
- **Validação contínua:** Entrevistas e testes manuais iterativos com utilizadores e profissionais da área para validação de funcionalidades.
- **Testes automatizados:** Suite de testes Pest/PHPUnit para validar funcionalidades críticas, regras de autorização e regressões.
- **Boas práticas de engenharia:** Isolamento de dados ao nível do modelo, políticas de autorização granulares, padrões de código consistentes e versionamento estruturado.


Desenvolvimento do projeto

Metodologia e Ferramentas

O projeto foi desenvolvido com a framework Laravel 12, utilizando Filament 3 como painel administrativo e PHP 8.2 como linguagem de backend. A base de dados MySQL foi modelada para suportar entidades principais como Utilizadores, Funcionários, Contratos, Departamentos, Designações, Localização geográfica (Países, Estados, Cidades), Registos de Trabalho (Worklogs), Banco de Horas (Hourbanks), Presença (Attendance), Férias (Timeoff) e Benefícios.

O desenvolvimento adotou uma abordagem iterativa com ciclos de 2 semanas, testes automatizados contínuos usando Pest/PHPUnit, validação manual de funcionalidades críticas e documentação do progresso paralela ao desenvolvimento.

Principais Implementações

**1. Arquitetura de Painéis e Autenticação**

- Implementação de três painéis separados: Admin, HR (Recursos Humanos) e Employee (Funcionário), cada um com recursos, páginas e widgets específicos.
- Sistema de autenticação unificado com suporte a múltiplos logins por painel (/admin/login, /hr/login, /employee/login).
- Middleware `EnsurePanelRole` que valida correspondência entre a função do utilizador e o painel acedido, redirecionando para a página de login correta em caso de acesso não autorizado.

**2. Controlo de Acesso e Autorização**

- Implementação de três funções principais: ADMIN (controlo total), HR (gestão de funcionários e processos), EMPLOYEE (acesso aos seus próprios registos).
- Políticas de autorização granulares aplicadas em cada recurso Filament, restringindo ações (criar, editar, eliminar, visualizar) conforme a função.
- Gates e middleware específicos para isolar dados e funcionalidades por painel.

**3. Sistema de Registos de Trabalho e Banco de Horas**

- Modelo `Worklog` para registar horas trabalhadas por funcionário com suporte a:
  - Registro de início e fim do período de trabalho
  - Suporte a pausas/almoços com campos `break_start` e `break_end`
  - Validação para garantir que pausas não excedem 2 horas e ficam dentro do período de trabalho
  - Cálculo automático de `hours_worked` e `extra_hours` com exclusão do tempo de pausa
  - Arredondamento para valores inteiros para facilitar relatórios e contabilização

- Modelo `Hourbank` para manutenção do banco de horas individual de cada funcionário
- Criação automática de registos de Hourbank ao registar um novo funcionário
- Atualização automática do saldo de horas baseada em horas trabalhadas, extra horas e períodos de férias

**4. Gestão de Recursos Humanos**

- Entidades principais implementadas:
  - `Employee`: Dados pessoais, contacto e localização geográfica de funcionários
  - `Contract`: Gestão de contratos com tipos de contrato, datas, salário e status
  - `Department`: Estrutura organizacional com departamentos
  - `Designation`: Cargos/posições com salário base
  - `Timeoff`: Gestão de períodos de férias e licenças com categorias (férias, doença, licença pessoal, etc.)
  - `Benefit`: Benefícios associados a funcionários
  - Localização: Países, Estados e Cidades para endereços dos funcionários

**5. Localização e Experiência de Utilizador**

- Tradução completa da interface para Português (pt-PT):
  - Labels, rótulos e nomes de colunas em Filament Resources
  - Mensagens de validação e feedback
  - Confirmações de ações e notificações
  - Dashboard e widgets

- Melhorias de UX:
  - Notificações customizadas para criação e edição de itens importantes (Employees, Contracts, Timeoff, etc.)
  - Confirmações ao cancelar edições para prevenir perda de dados
  - Badges coloridas para exibição de funções de utilizadores
  - Ações condicionais (visível apenas para funções autorizadas)
  - Dashboards personalizados com widgets mostrando métricas-chave (total de colaboradores, contratos ativos, férias pendentes, horas no banco)

**6. Política de Senhas e Segurança**

- Padronização de senha inicial para novos utilizadores (configurável via variável de ambiente `DEFAULT_USER_PASSWORD`)
- Campo `must_change_password` que marca utilizadores que precisam trocar senha no primeiro acesso
- Middleware `EnforcePasswordChange` que redireciona utilizadores para página de troca de senha obrigatória (/password/change)
- Implementação de rotas, controller e view para alteração segura de senha
- Campo `password_changed_at` para auditoria de histórico de alterações de senha

**7. Geração de Documentos**

- Integração com `barryvdh/laravel-dompdf` para geração e download de contratos em PDF
- Controller `ContractPdfController` para renderização de contratos com dados do funcionário e condições contratuais
- Ação de download integrada no Filament Resource de Contratos

**8. Validação e Testes**

- Suite de testes Pest/PHPUnit cobrindo:
  - Testes de autenticação e autorização
  - Validação de middleware de acesso por painel
  - Testes de funcionalidade de registos de trabalho e cálculo de horas
  - Testes de políticas de autorização
  - Validação de regras de negócio
- Configuração de testes com banco de dados em memória (SQLite) para rapidez
- Testes de regressão contínuos integrados no fluxo de desenvolvimento

Controlo de acesso por funções (ROOT, ADMIN, HR, EMPLOYEE) com políticas e gates reforçados, incluindo ações condicionais visíveis apenas para os perfis autorizados.
Registo de trabalho automático e cálculo de horas: suporte a pausas (‘break_start’ / ‘break_end’), exclusão do tempo de pausa nos cálculos, arredondamento para horas inteiras e atualização automática do ‘Hoursbank’ do funcionário.
Criação automática de registos de ‘Hoursbank’ no evento ‘Employee::created’ quando inexistente, com notificação específica.
Notificações: trait ‘NotifiesCreatedItems’ para notificações separadas por item criado e supressão das notificações padrão do Filament (‘SuppressesDefaultFilamentNotifications’).
Localização e i18n: tradução para pt‑PT de rótulos, formulários, colunas e mensagens de validação.
Validação e testes: ajuste de regras de autorização e correção de testes, suite de testes atualizada com sucesso (todos os testes passam localmente).
Paineis dedicados aos funcionários (/employee), administradores (/admin), aplicação geral (/app) e recursos humanos (/hr), apresentando páginas e middleware específicos para isolar dados e funcionalidades por função.

Melhorias UX: confirmações ao cancelar edições (‘ConfirmsCancelAction’), badges de função na tabela de utilizadores, e ações condicionais nas interfaces Filament.
Padronização de senha padrão para novos utilizadores com obrigatoriedade de mudança no primeiro acesso.
Isolamento de dados ao nível do funcionário para proteção de privacidade.
