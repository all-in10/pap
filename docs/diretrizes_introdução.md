1. Introdução
## 1.1. Enquadramento teórico
Explicar o tema do projeto e a sua relação com a área de Informática de Sistemas.
O aluno deve referir, por exemplo:
A importância da informática/sistemas na atualidade
A área específica em que o projeto se insere (redes, hardware, software,
segurança, suporte técnico, servidores, etc.)
Conceitos básicos necessários para compreender o projeto

📌 Não é para explicar tudo em detalhe técnico, mas mostrar que domina os conceitos principais.


## 1.2. Fundamentação do tema

Justificar porque escolheu este projeto.


Pode incluir:
Interesse pessoal do aluno
Utilidade prática do projeto
Problema que o projeto pretende resolver
Ligação do projeto ao perfil profissional do curso
Ex.:
“Este projeto foi escolhido por permitir aplicar conhecimentos adquiridos ao longo do curso,
nomeadamente na área de …”


## 1.3. Metodologia adotada
Explicar como o projeto foi desenvolvido.
Pode referir:
Tipo de projeto (prático, aplicado, experimental)
Ferramentas utilizadas (software, hardware, linguagens, sistemas)
Pesquisa realizada (manuais, tutoriais, documentação técnica)
Forma de trabalho (individual, autónoma, por etapas)

📌 Aqui não se avalia se ficou perfeito, mas se o aluno sabe explicar o processo.


## 1.4. Objetivos do projeto

**1.4.1. Objetivo geral** 
O que se pretende alcançar com o projeto (de forma global).

Ex.:
Desenvolver
Implementar
Configurar
Criar
Testar
**1.4.2. Objetivos específicos**

Passos concretos para atingir o objetivo geral.
Ex.:
Instalar determinado sistema
Configurar equipamentos
Testar o funcionamento
Documentar o processo
📌 Regra prática: objetivos começam sempre por verbos no infinitivo.
